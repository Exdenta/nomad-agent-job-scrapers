# SEO baseline — 2026-09-03

This is a dated pre-expansion baseline for `https://nomadagent.dev/`. It is not
a forecast and should not be presented as current after a later measurement.

## Deployment and crawl surface

- The then-current nine-page site was deployed on 2026-09-02 at approximately
  16:08 UTC.
- All nine canonical sitemap URLs returned HTTP 200 during the 2026-09-03
  read-only audit.
- HTTP, `www`, trailing-slash, and `index.html` variants redirected to the
  intended HTTPS apex clean URL.
- An unknown path returned HTTP 404.
- Each indexable page exposed one self-referencing canonical; `robots.txt` and
  the sitemap were readable.
- The live HTML, CSS, JavaScript, robots, and sitemap artifacts matched the
  audited repository files byte-for-byte.

These facts prove deployment and crawl configuration. They do not prove that a
search engine crawled, indexed, ranked, or sent traffic to a URL.

## Search-engine state

The latest signed-in console inspection on 2026-09-03 found:

- Google indexed the homepage; the eight new detail pages were not yet indexed.
- Bing reported all nine URLs as pending crawl and not indexed.

Because the detail pages were about one day old, this was recorded as an early,
non-actionable state. The existing monitor waits until at least 72 hours after
deployment before recommending per-URL intervention and does not resubmit URLs.

## Content and measurement state

- The website represented two Actors while the repository documented three.
- Three `nomad-ai-job-fit-*` schema `$id` URLs returned HTTP 404.
- The homepage H1 used the repository slug rather than a customer task.
- Detail pages were accurate but did not yet cover the complete evaluation and
  implementation task.
- CTA elements emitted local semantic events, but no confirmed analytics
  collector received them.
- Dependable keyword-volume, backlink-domain, conversion, and field Core Web
  Vitals baselines were not available.

## Comparison rules

Use the privacy-minimized weekly Search Console artifacts generated after this
baseline for traffic comparisons. Use raw-query exports only in a deliberately
private local review. Keep aggregate search performance, URL
indexing, local event emission, and attributable product activation as separate
evidence layers. Set numerical growth targets only after a complete 28-day
window exists.
