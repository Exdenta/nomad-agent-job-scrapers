Research and academic Actor

EURAXESS Jobs Scraper

Search PhD, postdoc, fellowship, research, and faculty vacancies while preserving research domains, requirements, funding, deadlines, contacts, and source taxonomy.

Supported build 1.0.16nomad-agent-job-v1Academic taxonomy
Open on Apify ↗Build a Sheets flow

What it is for

EURAXESS vacancies carry academic concepts that do not fit a generic job row cleanly. This Actor keeps those source fields in a separately versioned custom object while also producing the shared identity, data, LLM, and raw roots used by every Nomad Agent integration.

  • Use multilingual keyword expansion and source-specific research filters.
  • Preserve published funding, deadline, contact, programme, and researcher-profile evidence.
  • Choose canonical output when academic provenance matters; flatten only for a table destination.

Bounded starter input

EURAXESS recency has calendar-date granularity, so supported values begin at 24 hours.

{
  "schemaVersion": "nomad-agent-job-search-input-v1",
  "keyword": "machine learning",
  "location": "Spain",
  "postedWithin": "7d",
  "maxItems": 20,
  "translateToEnglish": false,
  "aiEnrichment": { "enabled": false },
  "includeRaw": false
}

Source semantics stay intact

null means unknown or unavailable. [] means the source established that a list is empty. Consumers must not collapse that distinction or infer missing requirements from nearby prose.

Completion proof

Require terminal success, authoritative build 1.0.16, a valid v4 RUN-SUMMARY, and dataset reconciliation before delivery.
