Why a research-specific contract matters

Academic vacancies carry concepts that a generic title-company-location row cannot express faithfully. The Actor maps common facts into the same six-root nomad-agent-job-v1 envelope as LinkedIn and retains source-specific research fields in a separately versioned custom object.

  • Preserve research domains, researcher profiles, programmes, funding, requirements, languages, deadlines, and named hiring contacts when the source publishes them.
  • Use source-specific filters and multilingual keyword expansion rather than assuming professional-job filters map one-to-one.
  • Keep the canonical dataset for research analysis; flatten only the fields a particular table destination can represent.

Bounded starter input

EURAXESS establishes calendar dates, not posting hours. The Actor accepts 24h, 7d, 30d, or any for recency and rejects 1h.

{
  "schemaVersion": "nomad-agent-job-search-input-v1",
  "keyword": "machine learning",
  "location": "Spain",
  "postedWithin": "7d",
  "maxItems": 5,
  "translateToEnglish": false,
  "aiEnrichment": { "enabled": false },
  "includeRaw": false,
  "dedupe": { "enabled": false },
  "analyticsEnabled": false
}

Read, search, and publishing feeds are different

EURAXESS publishes official guidance for organizations sending vacancy XML into its publishing system. That publisher feed is not a general read API for searching or exporting vacancies. This Actor independently reads public job listings and normalizes them for permitted downstream use; it is not an official European Commission endpoint or partner integration.

For authoritative source information, visit the official EURAXESS Jobs portal ↗. Review source terms, licensing, privacy requirements, and applicable law before crawling, retaining, or republishing any records.

Exact-run completion checklist

The current Store default observed on 2026-09-03 is build number 1.0.20 (immutable build 5n7huEXQYFUBdndQP). The checked-in integration pack is still tested against 1.0.16. Keep that older exact pin for maintained examples until the newer build completes contract and destination regression checks.

  1. Confirm current Actor access, then pin the intended build with an item and charge cap.
  2. Poll only the returned run ID; require terminal SUCCEEDED and the requested build.
  3. Read nomad-agent-run-summary-v4 from that run and apply its single bounded retry rule only when explicitly recommended.
  4. Fetch the selected run’s default dataset; reconcile its complete count with RUN-SUMMARY.delivered.
  5. Require the six canonical roots and identity.source = euraxess.

Evidence semantics

null means a fact is unknown or unavailable. [] means the source established that a list is empty. Static extraction, description-derived facts, normalized data, optional LLM metadata, and raw source material are separate layers. Do not turn nearby prose into a requirement or contact unless the contract records its provenance.

Troubleshooting

  • Unexpected zero rows: verify availability, the exact source filters, and a valid clean-empty summary before broadening the query.
  • Rejected recency: replace 1h with 24h or a broader supported calendar window.
  • Missing academic fields in Sheets: inspect the canonical custom object; the 32-field flat projection intentionally omits source-specialized detail.
  • Translated display text: keep the source-language evidence and translation metadata. A translation must not overwrite source provenance.
