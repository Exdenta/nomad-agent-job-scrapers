Try a five-job search

Open this tool on Apify ↗, sign in, and paste the example below into the Input JSON editor. Set a maximum run cost before starting.

Enter a term, choose a date range and start with five results. Paid extras are off. The Console example excludes raw descriptions and HTML; enable raw output to include them. API calls that omit includeRaw include raw data by default.

{
  "schemaVersion": "nomad-agent-job-search-input-v1",
  "keyword": "research",
  "postedWithin": "30d",
  "maxItems": 5,
  "dedupe": {
    "enabled": false,
    "key": ""
  },
  "aiEnrichment": {
    "enabled": false,
    "accuracy": "silver"
  },
  "translateToEnglish": false,
  "includeRaw": false,
  "analyticsEnabled": false
}

EURAXESS uses calendar dates: “24h” includes today and yesterday in UTC. Exact hourly filtering is unavailable.

Pricing and optional extras

Base results cost $0.90 per 1,000 jobs. 100 base results cost $0.09 in Actor result charges. Applicable platform costs are additional. Successful English translation adds $6 per 1,000 affected rows. Silver AI enrichment adds $6; Gold adds $10. Check current Apify pricing and set a maximum run cost. Prices checked September 6, 2026.

AI fills missing supported facts from the description and leaves published facts unchanged. Translation covers selected short display fields, not full descriptions. No customer AI or translation key is required. Neither AI profile guarantees accuracy.

Frequently asked questions

Can I repeat a search?

Yes. Cross-run deduplication is off by default. Enable it for alerts that should skip previously delivered jobs.

How many jobs can I collect?

Up to 200 jobs per run. Setting maxItems to 0 also means 200. This is a bounded current collection, not a complete historical archive.

Why did I get zero results?

Widen the date range or remove a restrictive keyword or country filter. If deduplication is enabled, earlier results may be skipped. A limited run is not proof that no matching jobs exist.

For developers and AI agents

Use the maintained integration guide for maintained latest examples and agent skill. Record the exact build returned by each run; a downloaded workflow is not evidence of the current release.

Require a successful run on the requested build. Read its RUN-SUMMARY and reconcile delivered with the full dataset count. Limited results are not a complete search; retry at most once only when recommended. Local integration tests do not prove hosted workflows or destination writes.

Each record uses nomad-agent-job-v1: schemaVersion, identity, data, custom, llm and raw. Null means unknown; an empty list means explicitly empty. Keep source academic labels distinct from applicant requirements.

Privacy and source information

This is an independent tool, not an official EURAXESS or European Commission integration. It uses public vacancy information. Optional AI sends description text to its provider; translation sends selected fields. Neither promises EU-only processing or zero retention. Aggregate analytics is opt-in.

Contact the vacancy publisher for corrections and the developer through Apify Issues for Actor data concerns. Keep applicant data out of searches, sanitize raw HTML, and review your obligations before republishing records. Visit official EURAXESS search for browsing and applications.
