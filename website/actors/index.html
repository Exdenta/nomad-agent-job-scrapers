Your first run

  1. Choose a tool above and follow its five-result example.
  2. Open the tool on Apify, sign in, set a maximum run cost, and start the small search.
  3. Inspect the output and source links. Export the data or connect a workflow when you're ready.

Base scraper results cost $0.90 per 1,000 jobs: 100 results cost $0.09 in Actor result charges. The scorer charges $0.02 per returned shortlist result. Optional extras and applicable platform costs are additional. See pricing details.

The scorer evaluates one candidate per run. Its built-in search covers supported developer-job sources; it does not submit applications or send alerts by itself.

For developers: formats and verification +

LinkedIn, YC, and EURAXESS return nomad-agent-job-v1. The scorer returns nomad-ai-job-fit-v1. Maintained integrations select latest; retain the immutable build returned by the run, inspect its RUN-SUMMARY, and reconcile its dataset. Verify each named destination separately.
