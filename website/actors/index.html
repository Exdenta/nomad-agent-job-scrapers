Job data and fit-scoring Actors

Collect source-linked jobs from LinkedIn, EURAXESS, or YC, or evaluate developer jobs for one candidate. The products share careful run controls, but their inputs, outputs, pricing, and evidence are deliberately distinct.

Y Combinator startup jobs

Use the normalized YC Actor for startup recruiting pipelines and recurring alerts. Complete descriptions, company context, stable identity, and a public schema support downstream processing. Base result events cost $0.90 per 1,000 jobs; enrichment and translation are optional.

Recency uses first observation, and runs filter a refreshed inventory. Unknown workplace modes remain unknown.

LinkedIn Jobs Scraper

Use the LinkedIn Actor for public professional vacancies, recurring alerts, trackers, and job-data products. It returns the canonical six-root nomad-agent-job-v1 record, keeps original listing identity, and can suppress previously delivered jobs inside an explicit deduplication scope.

  • Current Store default: check the current default build API for the build number and immutable ID.
  • Repository release selector: latest. Record the resolved build identity for every run.
  • First run: keep translation, AI enrichment, analytics, raw output, and cross-run deduplication off; request no more than five jobs.
  • Do not infer: a successful Actor run does not prove a named alert or table received rows.

EURAXESS Jobs Scraper | Full Details & AI Enrichment

Use the EURAXESS Actor for PhD, postdoc, fellowship, research, and faculty vacancies. It maps common fields into nomad-agent-job-v1 while retaining research domains, funding, programmes, requirements, deadlines, and contacts in a source-specific custom object.

  • Current Store default: check the current default build API.
  • Repository release selector: latest. Record the resolved build identity for every run.
  • Recency: starts at 24h because EURAXESS establishes calendar dates, not posting hours.
  • Source boundary: this is an independent integration, not an official EURAXESS publishing or partner API.

AI Job Search & Fit Scorer

Search 10 public developer-job sources or score your own job list against a résumé or profile. Get a ranked shortlist with a 0–100 fit score, a 0–5 delivery score after hard-requirement checks, evidence, skill gaps, and links to the postings. Default shortlist mode filters out holds, drops, failures, and scored rows below the delivery threshold; audit mode retains the complete decision set.

  • Current Store default: check the current default build API; maintained integrations use latest.
  • Meter: $0.02 for each returned shortlist row or retained non-failure audit row; the maintained five-result starter caps result charges at $0.10.
  • Separate contract: output is nomad-ai-job-fit-v1; candidate-safe destinations upsert by matchKey, not jobKey.

Shared proof rule

A page, template, validation test, deployment tag, or successful canary proves only its own layer. Before delivery, verify the returned run ID, terminal status, exact build, Actor-specific RUN-SUMMARY, and exact default dataset. Verify any named Slack, Google Sheets, Airtable, webhook, or other destination separately.
