LinkedIn Jobs Scraper

Find fresh public LinkedIn jobs with precise filters, source-linked identity, duplicate-safe recurring runs, and optional description-backed enrichment or English translation.

What it is for

Use this Actor when the source itself matters: broad professional hiring markets, saved searches, job-alert products, research datasets, or agent tools that must retain the original listing identity. The output uses the shared six-root contract, so downstream code can also consume EURAXESS without pretending the sources are identical.

  • Filter by keyword, location, recency, work arrangement, and supported advanced fields.
  • Suppress already-delivered jobs across scheduled runs with an explicit dedupe scope.
  • Keep enrichment, translation, raw descriptions, and analytics off until the workflow needs them.

Bounded starter input

Start small, verify the exact build, then expand only after the output and charge boundary are understood.

{
  "schemaVersion": "nomad-agent-job-search-input-v1",
  "keyword": "TypeScript developer",
  "location": "Spain",
  "postedWithin": "7d",
  "maxItems": 20,
  "translateToEnglish": false,
  "aiEnrichment": { "enabled": false },
  "includeRaw": false
}

Completion proof

A successful request is not yet a delivered workflow. Require terminal Actor success, authoritative build 1.0.2, a valid v4 RUN-SUMMARY, and reconciliation with the default dataset. Test Slack, Sheets, Airtable, or another named destination independently.

Output identity

Deduplicate with jobKey, derived from source:externalId. Titles and company names are display data, not stable identity.
