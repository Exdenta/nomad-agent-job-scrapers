What the toolkit enforces

  • Exactly six top-level canonical roots: schemaVersion, identity, data, custom, llm, and raw.
  • LinkedIn and EURAXESS source-specific field rules without erasing their differences.
  • Stable jobKey identity and a shared 32-field flat projection for tables.
  • Valid v4 RUN-SUMMARY counts and supported terminal outcomes.

Choose the right layer

Use a parser after retrieval when your application already owns run orchestration. Use an Agent Skill when the client also needs instructions for bounded input, exact-build calls, terminal-status checks, retry limits, retrieval, and presentation.

npx skills add https://github.com/Exdenta/nomad-agent-job-scrapers \
  --skill linkedin-enrich-translate-normalize-scraper

Preserve meaning

Do not coerce null to an empty list or infer absent fields from prose. The canonical record preserves source evidence; the flat mapper is a derived convenience for destinations.

Best for

Application validation, ETL, agent workflows, testing, and table projections without a runtime dependency stack.
