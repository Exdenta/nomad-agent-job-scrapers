Included workflows

  • LinkedIn daily alerts: bounded synchronous search, stable dedupe scope, and Slack, Telegram, or email routing.
  • LinkedIn Sheets tracker: validates completed runs before upserting on jobKey.
  • EURAXESS Sheets tracker: keeps academic source fields in the canonical record and writes the shared flat projection.

Safe activation sequence

  1. Import the chosen JSON into n8n.
  2. Add a scoped Apify credential and the one named destination credential.
  3. Keep LinkedIn on build 1.0.2 or EURAXESS on 1.0.16.
  4. Run manually with a small item and charge cap.
  5. Verify terminal status, build, RUN-SUMMARY, dataset, and the destination write before enabling the schedule.

Import is not deployment

The templates contain no credentials. A successful import or Actor run does not prove that a Slack channel, Telegram chat, mailbox, or spreadsheet received the intended records.

Best for

Recurring alerts, team notifications, and no-code job trackers that need explicit deduplication.
