Five scoped tools

The maintained profiles expose fetch-actor-details, call-actor, get-actor-run, get-dataset-items, and get-key-value-store-record. That is enough to run the bounded workflow without exposing every Actor or storage operation.

https://mcp.apify.com?tools=fetch-actor-details,call-actor,get-actor-run,get-dataset-items,get-key-value-store-record

Agent execution contract

  1. Inspect the selected Actor and its current input contract.
  2. Use generic call-actor with LinkedIn build 1.0.2 or EURAXESS build 1.0.16, plus item and charge caps.
  3. Wait for a supported terminal status.
  4. Verify the authoritative build and v4 RUN-SUMMARY.
  5. Read and validate the default dataset before presenting or delivering results.

Client setup is not a live run

A saved MCP profile proves only configuration. OAuth, an exact Actor run, dataset retrieval, and any named destination each need their own evidence.

Best for

Interactive job research, agent-driven alerts, and products that need bounded tool use with inspectable evidence.
