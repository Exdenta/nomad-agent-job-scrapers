EURAXESS jobs API and export options

Export EURAXESS research vacancies, build an alert, or connect structured job data to an app. Start with a five-result search.

Explore normalized EURAXESS jobsUse the REST pattern

Export research jobs in three steps

  1. Open the EURAXESS Jobs Scraper and search with five results first.
  2. When the run finishes, inspect the dataset and export JSON, CSV or Excel.
  3. For recurring workflows, use the API and integration examples, with the latest selector and a maximum run cost.

Choose the right access route

For browsing and applying, use official EURAXESS search. For structured exports and alerts, use this independent Actor. The official publisher XML feed submits vacancies; it is not a general job-search or export API.

What your export contains

Job title, institution, research fields, locations, deadlines, funding and application details when published. The full JSON example shows the field structure. Raw description text and HTML are optional. Missing facts remain null.

Costs and completion

Base results start at $0.90 per 1,000 jobs; optional AI and translation add charges. Check current pricing on Apify and use a run cost cap. For automations, validate the completed run, its RUN-SUMMARY and the dataset count. A partial or limited search is not complete coverage.

Responsible use

The Actor is independent of EURAXESS and the European Commission. Check the source for current vacancy details. Review source terms and your obligations before retaining or republishing data; keep applicant data out of searches. Optional AI and translation send the required text to their providers.
